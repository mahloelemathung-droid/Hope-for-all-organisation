## Hope for all organisation
#website description
this project is a website develped for Hope for all shelter.the website provides information about the organisation and allows people to enquire online.

## features
-homepage
-about us page
-services 
-enquiry form
-contact page

## installation/technoloies used
-html
-css

## how to run 
1. open the project folder in visual studio code
2.open index.html in your browser
3.open about.html in your browser
4.open contact.html in your browser
5.open enquiry.html in your browser
6.open services.html in your browser
7.open images folder in your browser
8.open media folder in your browser 
9.open assets\css folder in your browser
